Worker Estoque — pacote demonstrativo para GitHub Pages

Publique o conteúdo desta pasta na raiz do repositório; index.html fica na raiz. A interface, cores, telas e arquivos visuais vêm do sistema original enviado.

A carga local inicial inclui catálogo amplo, um ano de movimentações, históricos de terceirização em diferentes etapas, produtos dinâmicos com composições e componentes, lotes com datas de validade, tasks/pendências, compras parciais e eventos/mapeamentos de Mercado Livre e Shopee. Os canais e pedidos são fictícios, simulam visualmente uma conexão e não acessam contas ou APIs reais.

Os registros e alterações são guardados no localStorage deste navegador. Por ser uma base de demonstração local, cada navegador/dispositivo tem seus próprios dados. Faça backup pela tela Importar/Exportar antes de limpar armazenamento do navegador. O pacote não inclui Worker, D1 ou API; algumas operações avançadas originalmente processadas no servidor podem ter comportamento limitado no modo estático.
